An orders table from Rust

This page contains no JavaScript. The table below — rows, totals, and the click-to-select behaviour — comes from a 2.4 KB WebAssembly module compiled from plain Rust: no_std, no allocator, no wasm-bindgen. Click a row to select it; the module toggles the class from inside wasm.

Everything inside the panel came from wasm-dom-orders/src/lib.rs.
